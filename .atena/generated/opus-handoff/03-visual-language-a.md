# Opus handoff — Visual language reference batch A

## Gate

Use only after explicit approval to generate or curate visual references. This package produces references, not final game assets.

## Context

- `.atena/vault/drafts/2026-10-03-visual-language-guide.md`
- `.atena/vault/drafts/2026-10-03-master-asset-reference-manifest.md`
- Existing continuity references under `assets/concept-art/` and `assets/art/`.

## Scope and output

Produce a single master frame plus a palette/material board. Show Lolth, a wagon, a Thornwake enemy, a recoverable object, HUD space, parallax and cold-night/warm-fire contrast. Attach provenance, source terms, filename, hash, review notes and the proposed `TBD-A` cell/pivot decision to a manifest. Store only in a review directory; do not import into runtime.

## Non-goals

No production sprite sheet, animation, vendor asset admission, character redesign, UI implementation, runtime edit, dependency, remote publication or future chapter art.

## Acceptance

The frame must pass the four criteria in the visual guide at 1280×720. Output contains exactly the reference files and their receipt; any unclear license/provenance is reported as a blocker instead of being admitted.
